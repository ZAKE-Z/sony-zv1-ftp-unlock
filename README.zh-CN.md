# sony-zv1-ftp-unlock

[English](README.md) | 简体中文

把索尼 ZV-1 的“在电视上观看”入口替换为 FTP，修正初始化、照片传输、菜单及图标，另由独立脚本使用 JSON 配置九个 FTP 服务器。

**实验项目，仅在持有者的一台 ZV-1 上验证过。目前没有被证实能把相机所有文件和设置完美恢复到未修改的出厂状态的方法。重刷固件、机内初始化和本项目的还原操作，都可能留下可发现的痕迹；使用前请充分考虑。** 固件仅支持 `29114_04.2021031701`。此前版本已成功连接并传照片；最新菜单／字符输入补丁以及此次重构后的刷写、还原、版本脚本尚未完整实机验证。

## 准备

1. 安装普通 **64 位 Python 3.10 或以上**，推荐 3.12，并勾选加入 PATH。不再提供 `runtime/python.exe` 或打包 `site-packages`。脚本自动用当前解释器的 pip 安装缺失依赖，也可先执行 `python -m pip install -r scripts/requirements.txt` 或 `python scripts/setup_environment.py`。
2. 手动下载 **a7 III 4.01** 和 **a7C 2.00** 两份 Windows 固件，放进 `firmware/`。无需改名，内容必须符合指定哈希。[下载链接、机型版本、命名和提取说明](docs/FIRMWARE_SOURCES.zh-CN.md)。
3. 执行 `python scripts/zh_1_提取固件.py`。缺少库时解锁脚本也会自动提取。脚本不自动下载固件，仓库不包含索尼库文件。
4. 运行第 3 步前，把 `ftp_config.example.json` 复制为 `ftp_config.json`，填写九槽位的实际服务器地址和端口。默认均为 `127.0.0.1:21`，不能直接传照片。省略用户名／密码保留机内值，空字符串清空；九个槽位均会写入。`selected_slot: null` 保留有效当前槽位，否则选 FTP1。
5. 相机开机，以“大容量存储”连接，仅接一台相机。使用已验证可用的 USB 服务驱动。配置 Python 不等于安装设备驱动，本项目不自动更换 Windows 驱动。

## 根目录 CMD 启动入口

| 操作 | Python 脚本 | 双击入口 |
| --- | --- | --- |
| 固件提取 | `python scripts/zh_1_提取固件.py` | zh_1_提取固件.cmd |
| 解锁 FTP 固件 | `python scripts/zh_2_解锁FTP.py` | zh_2_解锁FTP.cmd |
| 写入或更新九槽位配置 | `python scripts/zh_3_写入配置.py` | zh_3_写入配置.cmd |
| 还原固件修改 | `python scripts/zh_4_还原.py` | zh_4_还原.cmd |
| 把报告版本改为 2.00 | `python scripts/zh_5_修改版本号.py` | zh_5_修改版本号.cmd |

Python 实现位于 `scripts/`，根目录 CMD 自动调用；不依赖旧 GPT 目录。

- `python scripts/zh_2_解锁FTP.py --validate`：只检查本地固件资源。
- `python scripts/zh_2_解锁FTP.py --check`：只读相机固件。
- `python scripts/zh_2_解锁FTP.py --verify`：只读核验 FTP 固件已安装。
- `python scripts/zh_3_写入配置.py --validate`：只检查 JSON 和本地加密工具。
- `python scripts/zh_3_写入配置.py --check`：只读核验相机已安装 FTP 固件；`--verify`：只读核验机内 FTP 配置。
- `python scripts/zh_4_还原.py --check`、`python scripts/zh_5_修改版本号.py --check`：只读相机预检。
- `--help`：只显示用法，不连接相机。

第 2 步仅修改固件，不写服务器配置；第 3 步支持 `--config 路径`，以后可单独更新 FTP 地址。不自动开启 FTP，不改 Wi-Fi 或 USB 设置。保留有线／无线选择，但未证明 ZV-1 可使用有线 FTP；最终菜单隐藏保存／加载，移除重复自动传输。此前实机已确认传照片及 DISP 无信息显示时隐藏 FTP 图标。

## 还原与版本修改的区别

`zh_4_还原.py` 恢复四个已知被修改的系统文件为原版字节，删除四个校验匹配的新增库。只接受原版或此项目最终版，不接受未知或早期中间修改状态。**清除 FTP 配置，不是恢复出厂设置**；FTP 地址、账号密码、开关和缓存恢复已验证的空默认值，Wi-Fi 与 USB 保留。写入前备份，写后核验并重启。新还原脚本仅完成离线检查，尚未实机测试；掉线或断电可能使操作不完整，需要查看保存的报告。

`zh_5_修改版本号.py` 只把 `/setting/updater/dat4` 记录改为 2.00，**不是刷入旧固件，也不撤销补丁**。可以尝试第 4 步还原脚本、机内初始化，或先改报告版本号再使用索尼官方升级程序重装 2.01；这些是不同的还原途径，可以按实际情况组合使用。即使重新刷入 2.01，也不能保证所有修改及痕迹都被清除，无法承诺相机回到完全未改动的原始状态。本项目不自动运行官方升级器或机内初始化。

## 仍需注明的问题

首次启用 FTP 时，机内可能无法手动填写或确认服务器 IP、端口；早期测试中这类故障较常见。之后有时会自行恢复正常，具体原因尚不清楚。如果始终无法输入，请编辑根目录的 `ftp_config.json`，填写服务器地址与端口，再运行第 3 步写入配置。用户名和密码的机内输入此前可以正常使用。最新菜单光标与输入保护仍需进一步验证。不要同时运行其他连机修改工具。

`logs/` 含固件原件及私有配置，不要公开。下载的固件和生成的库已忽略。重建仓库不含索尼固件／库、打包 Python、私人配置和早期逆向资料。

离线检查：`python -m unittest discover -s tests -v`。本地固件提取已用保存的原始固件完整验证，但不能据此声称相机刷写流程也验证完成。

项目由相机持有者主导实机验证，使用 AI 协助固件分析、脚本编写和文档整理。原创代码尚未指定开源许可证；第三方 PMCA/fwtool 保留 MIT 许可。

## 目录整理与重启等待

根目录保留十个 `.cmd` 入口、中英文 README 和 FTP 配置文件。Python 实现及同名语言入口位于 `scripts/`，双击 CMD 自动调用，无需单独打开 PY。
`resources/` 保存固件清单及补丁数据，`assets/` 保存所需工具／本地生成库，`docs/` 保存详细说明，`firmware/` 放手动下载的固件，`logs/` 保存私人操作记录。
固件写入导致重启后，不再等待固定 8 秒就自动继续：请等待相机和 USB 恢复，按任意键才进行重启核验。第 3 步是独立操作，等待相机与 USB 恢复后再运行；以后可重复运行第 3 步更改服务器，不必重新刷写固件。
按 Esc 只取消尚未执行的步骤，不撤销已经完成的固件修改。新的等待流程仅完成离线检查，尚需实机验证。

还原脚本现已清除九个 FTP 槽位、账号密码、目录、相关开关和缓存；使用原机未配置时的有效默认结构，不覆盖整份 Backup.bin。即使固件文件已是原版也会清除配置。写入前保存私人备份、写后回读并保存核验结果。此配置清除流程仍需实机测试。重启前文件和配置已核验时，特定的设备断开错误会记为重启断连，不再报还原失败；这不代表完成了重启后核验。

配置工具记录：此前 149108 字节的版本在相机内触发非法指令，配置没有写入。现在依照历史上成功运行的工具编译、链接方式，重建为 4636 字节；配置脚本现于同一次 USB 调试会话中核验固件并写入设置；先前连续开启第二次会话时检测到 0 台相机。2026-10-12 九槽位写入及机内回读通过，持有者确认 FTP1 显示 127.0.0.1:21。使用这个重建工具连接实际服务器仍未测试。
