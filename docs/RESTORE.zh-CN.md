# 还原途径与限制

可以尝试几种办法撤销 FTP 修改，但目前没有哪种方法被证实能让相机的所有文件和设置完全恢复到未改动的出厂状态。

1. 先运行 `python scripts/zh_4_还原.py --check` 做只读预检，再运行 `python scripts/zh_4_还原.py`，还原已支持的原版文件字节、删除哈希匹配的新增库，并清除 FTP 配置。Wi-Fi 与 USB 设置保留。未知中间版本会被拒绝。私人备份和报告保存在 `logs/restore-*`。脚本核验重启前的结果，不声称已完成重启后的内存核验。新还原流程尚未完成实机测试。
2. 视需要使用相机自身的初始化。持有者此前发现，官方重装 2.01 后还需要机内初始化才能恢复正常操作；这并不能证明所有 FTP 配置或修改痕迹都被清除。
3. 可选的 `python scripts/zh_5_修改版本号.py` 仅把报告版本记录改为 2.00；之后可由持有者另行使用索尼官方 ZV-1 升级程序重装 2.01。脚本自身不会重装固件或撤销补丁。不要把 a7 III 或 a7C 的升级程序用于 ZV-1。

这些途径可以组合使用，但即便官方重刷 2.01，也可能留下可发现的改动。请勿把其中任何一种视为彻底恢复出厂状态。确认相机运行状态前，保留私人备份和报告。
